# Privacy and Publication Notes

This is the **public, anonymized documentation edition**, updated through 8 October 2026. It retains hardware models, software versions, service ports, resource measurements and learning outcomes.

| Information | Handling |
|---|---|
| Real LAN/upstream IPv4 addresses | Replaced with documentation-only ranges |
| Unique IPv6 addresses/prefixes | Omitted |
| Original hostnames and remote IDs | Replaced with role aliases |
| SSIDs and WPA credentials | Omitted |
| Passwords, API/auth tokens, VPN keys and recovery material | Excluded from examples and evidence |
| MACs, serials and full hardware/storage identifiers | Omitted |
| Accounts, personal usernames, email, browser profiles/tabs | Omitted |
| Personal device inventory, query history and precise activity timestamps | Omitted |
| Original screenshots and photographs | Excluded from the archive |
| Raw logs, configuration exports and backups | Excluded from the archive |

[Sanitized evidence](sanitized-evidence.md) replaces images with anonymized tables and excerpts. Original attachments are not altered by this update. No original-to-fictional identity map is bundled.

`192.0.2.0/24` represents the lab; `198.51.100.0/24` represents the upstream. These addresses are for documentation, not deployment. `pve-core` means the VAIO role and `pve-compute` the HP role; these aliases do not imply renaming either machine. Public DNS `1.1.1.1` and vendor URLs retain their technical meaning.

Sanitization applies to this replacement archive. It does not edit earlier chat messages, rotate credentials, change equipment settings, rewrite existing Git history or delete previously downloaded copies. If an actual credential was published elsewhere, hiding it here does not invalidate it; rotation is separate.

This update did not push files to a GitHub repository. Review any new image or transcript before publication, including metadata, addresses, identifiers, account details, browser context and query history. Covering a password field alone is insufficient.

The `.gitignore` excludes raw screenshots, common private folders, credential files and archives from routine staging. It cannot remove already tracked files or guarantee privacy.

Reference: [RFC 5737](https://www.rfc-editor.org/rfc/rfc5737).
